# Security Policy

## Reporting a vulnerability

If you discover a security issue in this repository, please avoid publishing exploit details in a public issue before the problem can be assessed. Open a minimal issue requesting a private contact path, or use GitHub's private vulnerability reporting feature if it is enabled for this repository.

Please include the affected version or commit, a concise description, reproduction conditions, and the expected security impact.

## Scope

This project focuses on defensive research for speech deepfake detection and audio forensics. Security reports related to dependency risks, unsafe file handling, protocol parsing, model-loading behavior, or reproducibility infrastructure are welcome.

Reports that primarily request assistance with impersonation, deceptive audio generation, evasion of detection systems, or other abusive uses are outside the intended scope of the project.
