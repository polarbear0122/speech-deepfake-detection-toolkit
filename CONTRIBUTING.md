# Contributing

Thanks for your interest in improving the Speech Deepfake Detection Toolkit.

## Ways to contribute

You can help by:

- Adding reproducible baselines for spoof detection or attack attribution.
- Improving dataset protocol loaders.
- Adding feature extraction or evaluation utilities.
- Improving documentation and examples.
- Reporting reproducibility issues or edge cases.

## Development workflow

1. Fork the repository and create a focused branch.
2. Keep changes small and clearly scoped.
3. Add or update tests/examples when behavior changes.
4. Document assumptions, dataset requirements, and evaluation protocols.
5. Open a pull request describing the motivation, implementation, and validation.

## Research contribution guidelines

For experimental results, please include enough information to reproduce the setting: dataset split/protocol, preprocessing, model/back end, random seed when relevant, metric definitions, and hardware/software dependencies when they materially affect results.

Do not submit proprietary datasets, copyrighted audio, credentials, API keys, or personally sensitive data.

## Responsible use

Contributions should support defensive security, academic research, benchmarking, provenance analysis, or other legitimate synthetic-media safety use cases.
